# salary_predictor-ibm-autoai
# 💰 Salary Prediction using IBM Watson AutoAI

## 📌 Project Overview

Salary Prediction is a Machine Learning project developed during my IBM internship.

The project uses IBM Watson AutoAI to automatically build, compare, and optimize multiple Machine Learning pipelines for predicting salary values from a salary dataset.

The experiment generated multiple ML pipelines and evaluated them using Root Mean Squared Error (RMSE) with cross-validation.

---

## 🎯 Objective

The main objective of this project is to develop a Machine Learning model that can predict salary based on available features in the dataset.

The project also demonstrates how IBM Watson AutoAI can automate important Machine Learning tasks such as:

- Data preprocessing
- Feature engineering
- Algorithm selection
- Hyperparameter optimization
- Model evaluation
- Pipeline comparison

`salary_data.csv`

---

## 🤖 Machine Learning Approach

IBM Watson AutoAI automatically generated and evaluated multiple Machine Learning pipelines.

The experiment generated:

**8 ML pipelines**

Different combinations of algorithms, feature engineering and hyperparameter optimization were evaluated.

---

## 📊 Model Evaluation

The models were evaluated using:

### Root Mean Squared Error (RMSE)

RMSE measures the average magnitude of prediction errors.

A lower RMSE generally indicates that the predictions are closer to the actual values.

The best-performing pipeline in the experiment achieved:

**RMSE: 12697.678**

---

## 🏆 Best Pipeline

The top-ranked pipeline was:

**Pipeline 8**

Algorithm:

**Snap Decision Tree Regressor**

Enhancements included:

- Hyperparameter Optimization
- Feature Engineering
- Additional Hyperparameter Optimization
